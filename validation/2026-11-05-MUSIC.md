## What the populated control adds

The prior fixture was an **empty playlist** and an SFX metadata declaration.
The new populated music control supplies song content and playlist mixer state.
Its `MusicTrackInfo._trackVolumes` contains the actual `Master` audio stem at
**0.8 / 80%**: Dictionary Version 2, HashSize 3, String/Single KeyValuePairs.
Both old ForgeBridge entries had empty dictionaries (Version 0, HashSize 0,
no pairs); the expanded native control showed Master 80%, while the original
generated OGG's expanded mixer was empty. The writer now initializes the stem
it emits. This fixes the observed representation mismatch; audible acceptance
of the rebuilt package remains pending, not inferred.

Native user `ContentItem` has `_filePath` and `_content`, without the older
shipped-layout `_officialFlag`. The audio schema now matches that declaration.
Song `_isSong` is True and metadata `_official` is False. No song payload,
duration, codec, original filename, metadata or song path changed in the
two-track repair: five of six generated native files are byte-identical to the
previous experiment. Only the playlist `.rwpl` changes; it is installed in a
new visible folder to preserve a user-edited predecessor.

The native importer embedded WAV (`RIFF/WAVE`), MP3 (`ID3`) and Vorbis (`OggS`)
verbatim in each song's `.rwfile`, with matching `_originalFile` extensions.
No encoded sidecar exists beside the song records. The native classes contain
duration and a byte-array length; no separate codec/rate/bitrate field was
found in the captured declarations. These values come from encoded payloads:
control MP3 is 22,050-Hz mono (32-kbit/s stream); control OGG is 22,050-Hz mono
Vorbis; the original experiment's MP3 is 44,100-Hz stereo (~158 kbit/s), and
OGG is 44,100-Hz stereo Vorbis (nominal 128 kbit/s), both ~61.04 seconds.
Full codec descriptions, lengths, headers, hashes and member declarations are
in the JSON. Toolkit borrowed no ForgeBridge-side dependency; the small synthetic
variants used the separate installed PySceneDetect encoder, not Toolkit ffmpeg.
Whole native files need not be byte-identical across serializers: NRBF object
IDs, optimized byte-array records and unused list capacity can differ. The
tests explicitly preserve payload bytes and compare logical typed values;
raw fixture bytes and their hashes remain unchanged.

Native-control initial silence was later superseded by Jeffrey confirming all
three audible. No particular intervening setting/session change was established.
Production conversion remains OGG-only until generated MP3 acceptance is
demonstrated; the MP3 here is an explicitly authorized experiment.
