# Fixtures

These packages were written for ForgeBridge. They are not Foundry VTT products, not Arkenforge content, and not copies of anyone else's module or world.

`synthetic-module` is a module folder whose compendium packs are NeDB-style JSON lines, the legacy text format described in Foundry's Version 11 packaging article. `synthetic-leveldb` is a module whose `packs/actors` directory is a LevelDB database generated by `scripts/build_synthetic_leveldb.py`. `synthetic-leveldb-scene` is a module whose `packs/scenes` directory is a LevelDB database from that same script, holding one scene. `synthetic-leveldb-scene.zip` is that module packed with a single top-level folder. `leveldb-pointer` only imitates the shape of a LevelDB pack directory (`CURRENT` plus a `.ldb` file). The bytes inside it are not a real LevelDB database. The reader reports that it could not open them. It does not treat those bytes as documents or as code.

Do not replace these with downloaded commercial modules, worlds, or marketplace assets.
