# Fixtures

These packages were written for ForgeBridge. They are not Foundry VTT products, not Arkenforge content, and not copies of anyone else's module or world.

`synthetic-module` is a module folder whose compendium packs are NeDB-style JSON lines, the legacy text format described in Foundry's Version 11 packaging article. `leveldb-pointer` only imitates the shape of a LevelDB pack directory (`CURRENT` plus a `.ldb` file). The bytes inside it are not a real LevelDB database and must not be decoded as documents or run as code.

Do not replace these with downloaded commercial modules, worlds, or marketplace assets.
