# Toolkit-made 5e note controls

These original `.rwnote`/`.rwmeta` pairs were captured on 2026-11-02 from
Toolkit-created FBCapture 5e Character, Item and Spell notes. Original paths:
`C:\Program Files (x86)\ArkenforgeData\MyAssets\Encyclopedia\Notes\FBCapture 5e <type>.rwnote`
and the matching `.rwmeta`. Treat the committed bytes as read-only references.

On 2026-11-03, Windows / Toolkit **0.5.1.18**, Notes → FBCapture 5e Spell → Open
confirmed the existing Spell reference is complete: Spell Name; 1st-level
divination; Casting time 1 round; Range Self; Components V S M; Duration 1 round;
Attack/Save None; Damage/Effect None; Spell description; At higher levels
Improved spell effect. The inert file graph has one `ArkenNoteField5eSpellBlock`
with all ten text members plus field name, UID and player visibility.
No replacement capture was needed. The original three test notes were later
deleted in Toolkit with Jeffrey's confirmation; these fixture copies remain.
The schema-built campaign writer already uses these templates for available
world spells; resolving external system-compendium spells is a separate task.
